# Contributing

Thanks for helping improve `repoaudit`.

## Setup

1. Fork and clone the repository
2. Run `npm install`
3. Run `npm test`
4. Make your change on a feature branch

## Guidelines

- Keep checks focused and explainable
- Prefer clear messages and actionable hints
- Add or update tests for new check behavior
- Keep the CLI surface small (`path`, `--json`, `--strict`)

## Pull requests

- Describe what changed and why
- Mention any checklist items you verified locally
- Keep commits readable

Bug fixes, new checks, docs improvements, and better false-positive handling are all welcome.
